GopherGPT — маленький трансформер-декодер, целиком написанный на чистом Go:
без PyTorch, без Python, без GPU. Обучается он **прямо на Black Shark 2**
(Snapdragon 835, 2017) внутри Termux + PRoot Debian. Ночью, пока телефон
заряжается, тренер гонит десятки тысяч шагов градиентного спуска; днём этот
же телефон — обычный карманный телефон владельца.

Проект начался с форка [zakirullin/gpt-go](https://github.com/zakirullin/gpt-go) —
прекрасной учебной реализации, сопровождающей курс Карпатого
[Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) —
и вырос в собственный ML-конвейер на устройстве: ночная тренировка с
чекпойнтами, контроль переобучения, юридический корпус и агент сбора данных,
который добывает публичные судебные решения прямо с телефона.

## Модель

| | |
|---|---|
| Архитектура | трансформер-декодер: 4 блока x 4 головы, embedding 88 |
| Параметры | 1 451 000 |
| Окно контекста | 32 токена |
| Словарь | 6060 склеенных токенов (англ. забег) / 218 символов (юридический) |
| Оптимизатор | AdamW, косинусный lr + прогрев 500 шагов, клип градиентов 1.0 |
| Чекпойнт | ~5,8 МБ float32, автосохранение каждые 500 шагов |
| Память тренировки | ~100–160 МБ RSS |

## Как строился этот репозиторий

Репозиторий — сам по себе эксперимент «человек направляет, ИИ исполняет».
Владелец руководит проектом с телефона; удалённый агент-наставник
проектирует изменения по ML и раскатывает их по SSH; агент на самом
устройстве (OpenCode) собирает данные через браузер телефона. Git-история —
живая стенограмма этого сотрудничества, включая фиксы, закоммиченные
не останавливая идущую тренировку.

## Что мы добавили к gpt-go

- Флаги `-steps -save-every -eval-every` + автосохранение — ночная
  тренировка, которая переживает убийство процесса и стартует тёплым
  рестартом с последнего чекпойнта
- `-corpus -topk -temp -prompt` — свои датасеты и управление сэмплированием;
  починка REPL; безопасное кодирование токенайзера
- Валидационный сплит (каждая 10-я полоса корпуса, оценка без градиентов) —
  чтобы ловить переобучение до того, как оно станет модным
- Косинусное расписание lr с прогревом + глобальный клип градиентов
  (защита от классических взрывов лосса посреди тренировки)
- Юридический конвейер данных: кодексы, классика теории права,
  синтетический учебник и живые решения судов из публичного реестра

## Запуск

Нужен Go 1.22+ — на компьютере или прямо в [Termux](https://termux.dev)
на телефоне (`pkg install golang`):

    go run .                                   # тренировка на вшитом корпусе Верна
    go run . -chat                             # поговорить с обученной моделью
    go run . -corpus my.txt -topk 8 -temp 0.8  # свой корпус + сэмплирование

## Честные ограничения

- Игрушечный масштаб: 1,45 млн параметров не дадут связной прозы. Цель —
  понимание стека целиком, а не продукт.
- Юридическое дообучение имитирует *стиль* юридических текстов.
  Это не юридическая консультация.
- Телефон — медленный тренер: прогресс измеряется ночами, а не GPU-часами.
