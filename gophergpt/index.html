Что это такое

GopherGPT — маленький decoder-only трансформер, целиком написанный и обученный на Go. Железо — Black Shark 2 2017 года с Snapdragon 835: ночью, пока телефон заряжается, тренер гонит десятки тысяч шагов градиентного спуска по корпусу Жюля Верна; днём это снова обычный телефон владельца с мессенджерами. Вся ML-математика — умножения матриц, attention, AdamW — работает на чистом Go в Termux, без единого вызова Python-экосистемы.

Проект вырос из учебной реализации zakirullin/gpt-go (сопровождает курс Карпатого Neural Networks: Zero to Hero) и превратился в собственный on-device конвейер: ночные тренировки с автосохранением и тёплыми рестартами, валидационный контроль, косинусное расписание с прогревом, клип градиентов — и сборка данных для следующего забега прямо с телефона.

Архитектура: 4 блока × 4 головы внимания, embedding 88, окно контекста 32 токена, словарь 6 060 BPE-токенов. Чекпойнт — ~5.8 МБ float32, автосохранение каждые 500 шагов: Android дважды убивал процесс — тренировка каждый раз подхватывалась с последнего чекпойнта без потери истории.

Путь лосса

Кривая обучения по живым логам: от 8.69 на старте до плато ~4.5 — это согласуется с арифметикой Chinchilla для корпуса в 1.05 млн токенов (78 эпох — уже много, модель упёрлась в данные, а не в размер).

Скорость зависит от того, спит ли владелец: ~1.4 шага/с ночью, ~0.15 — когда телефоном пользуются днём.

Как устроен трансформер

Модель — классический GPT: текст нарезается на токены BPE, каждый превращается в вектор-embedding, четыре одинаковых блока перемешивают информацию через multi-head attention и полносвязные слои, и на выходе softmax выбирает следующий токен. Вся математика — на матрицах из pkg/: matmul, softmax, AdamW — написаны руками, чтобы понимать каждую строчку.

Быстрый старт

Из бинарника (Linux/macOS):

gunzip gophergpt-v0.1.0-linux-amd64.gz
chmod +x gophergpt-v0.1.0-linux-amd64
./gophergpt-v0.1.0-linux-amd64 -chat          # поговорить с обученной моделью

Из исходников (нужен Go 1.22+ — прямо в Termux на телефоне тоже работает):

git clone https://github.com/Sereban-glitch/Sereban-glitch.github.io
cd Sereban-glitch.github.io/gophergpt
go run .                                          # тренировка на встроенном корпусе Верна
go run . -chat                                    # чат после тренировки
go run . -corpus my.txt -topk 8 -temp 0.8         # свой корпус + управление сэмплингом

Флаги проекта: -steps · -save-every · -eval-every · -corpus · -topk · -temp · -prompt · -chat

Дорожная карта

  • ✔ Фаза 0–1 — аудит устройства, сборка, демо 1 000 шагов (лосс 8.69 → 6.85)
  • ⟳ Фаза 2 — ночная тренировка 80 000 шагов: идёт ~57k, лосс 4.56; валидация + cosine LR + клип уже в деле
  • ⟳ Фаза 2.5 — юридический корпус: кодексы и классика собраны, живые решения судов ЕДРСР добывает агент
  • Фаза 3 — «Лламизация»: RMSNorm, RoPE, SwiGLU, KV-cache, weight tying, быстрые графы autograd
  • Фаза 4 — модель класса Gemma 270M через GoMLX
  • Фаза 5 — модель как собеседник внутри терминального агента

Честные ограничения

Это масштаб игрушки: 1.45 млн параметров не напишут связное эссе — цель проекта понять весь стек до дна, а не выпустить продукт. Юридический тюнинг имитирует стиль документов, а не даёт юридических советов. И телефон — медленный тренер: прогресс измеряется ночами, а не GPU-часами.

Как строился этот репозиторий

Репозиторий — сам по себе эксперимент «человек руководит, ИИ исполняет»: владелец ведёт проект с телефона, удалённый агент-наставник проектирует ML-изменения и раскатывает их по SSH, агент на самом устройстве (OpenCode) собирает данные через браузер телефона. Git-история — живая стенограмма этого сотрудничества, включая фиксы, закоммиченные прямо во время идущей тренировки.
